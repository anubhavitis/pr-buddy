pr-buddy

Understand-first file order for GitHub pull requests.

A Chrome overlay on the Files tab. A local model reorders the tree and stacked diffs. You still write every comment.

Download host (Mac M-series) Download extension

Use

  1. Run the host. Leave it running on 127.0.0.1:17342.
  2. If macOS blocks the binary: right-click → Open.
  3. Unzip the extension. Chrome → chrome://extensions → Developer mode → Load unpacked.
  4. Open a PR Files tab. Click the pr-buddy pill.
  5. Pick claude, grok, or mlx. Write comments in GitHub.

Need Chrome, an Apple Silicon Mac, and one backend already installed. No Go or npm. Host forgotten → the popup says offline.
