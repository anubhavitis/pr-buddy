pr-buddy

Understand-first file order for GitHub pull requests.

A Chrome overlay on the Files tab. A local model reorders the tree and stacked diffs. You still write every comment.

Download host (Mac M-series) Download extension

Install — two pieces

  • 1

    The host binary

    Connects your machine's AI backend to the browser. Run it and leave it running on 127.0.0.1:17342. If macOS blocks it: right-click → Open.

  • 2

    The Chrome extension

    Unzip it, then Chrome → chrome://extensions → Developer mode → Load unpacked. Open a PR Files tab and click the pr-buddy pill.

Install the host first — the extension needs something to talk to. If it is not running, the overlay says host offline — start pr-buddy-host; start the binary and click again. Needs Chrome, an Apple Silicon Mac, and one of claude, grok, or mlx already installed. No Go or npm.

How it works

Two installs. The extension rewrites the GitHub page; the host runs your model. They talk over 127.0.0.1:17342 — a port on your own laptop.

The extension sends the file paths, the PR title and description, and the head SHA. Your diff is never sent — pr-buddy never checks out, builds, or runs the branch. claude and grok reach their vendor API with that same metadata; mlx stays fully offline.
